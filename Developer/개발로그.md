
# Re:Boot 서비스 개발 로그

## 📅 [2026-02-11] 1차 백엔드 구축 및 프론트엔드 기초 설계

### 🎯 작업 목표
- "Re:Boot" 서비스의 핵심 가치(완주율, 자산화) 구현을 위한 데이터베이스 및 백엔드 로직 완성
- AI 기능(Whisper, RAG) 통합 및 프론트엔드 기본 구조 수립
- 강사/관리자용 홈페이지 부재 문제 해결

### 📝 진행 내용

#### 1. 데이터베이스 스키마 설계 및 백엔드 구현 (Django)
- **앱 구조**: `users`, `lectures`, `ai_tutor`, `analytics`, `assets`, `career`
- **핵심 모델링**:
    - `User`: 커스텀 유저 모델 (이메일 로그인, 커리어 목표 관리)
    - `Lecture`: `pgvector` 기반 임베딩 필드 포함
    - `SkillBlock`: 학습 성취도 기반 데이터 자산화
    - `MockInterview`: 6종 페르소나 기반 모의 면접 세션
- **API**: ViewSet과 Serializer를 이용한 RESTful API 뼈대 구축 완료

#### 2. AI 기능 통합 (OpenAI Integration)
- **OpenAIService**: Whisper(STT), GPT-4o(Chat), Embeddings 연동 완료
- **RAGService**: 질문 기반 유사 강의 검색(Vector Search) 및 컨텍스트 기반 답변 추출 로직 구현

#### 3. 프론트엔드 기초 구축 및 강사 페이지 추가 (Vue.js)
- **디자인**: Glassmorphism 테마(CSS 변수) 적용 및 레이아웃 구성
- **라우팅**: Dashboard, Classroom, MyPage 경로 설정
- **강사 대시보드 (New)**: 강의 업로드 및 AI 처리 상태(STT/임베딩) 확인을 위한 강사용 관리 페이지 프로토타입 구현

#### 4. 개발 편의성 개선
- `Developer/Execution_guide.md`: 실행 가이드 정리
- `start.bat`: 원클릭 실행 스크립트 작성
