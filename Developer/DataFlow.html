Re:Boot 데이터 흐름도 (Data Flow Architecture)

📌 데이터 흐름 요약 (Data Flow Summary)

1. 사용자 (User): 화면(Frontend)에서 클릭이나 입력을 통해 요청을 시작합니다.
2. 프론트엔드 (Frontend): 사용자의 행동을 API 요청(Request)으로 변환하여 백엔드로 보냅니다.
3. API (Backend): 요청을 받아 보안 검사를 하고, 필요한 데이터를 DB나 AI에게 요청합니다.
4. DB / AI: 실제 데이터를 저장/조회하거나, 지능적인 답변을 생성하여 반환합니다.
5. 응답 (Response): 처리된 결과가 역순으로 사용자 화면에 표시됩니다.
